# 진주텃밭 홈페이지

진주우리먹거리협동조합 진주텃밭의 소개 페이지. 배포 목표 도메인은 `jjcoop.co.kr`.

## 구조

정적 페이지 한 장이다. 빌드 도구·프레임워크 없음.

```
index.html   전체 페이지 (CSS 인라인)
img/         WebP 이미지 + 로고
```

## 자료 출처

| 내용 | 출처 |
|---|---|
| 조합원·직원 수, 매장 3곳 | 제13차 대의원총회 자료집 (2025-12-31 기준) |
| 조합 목적, 조합원 유형, 출자 좌수 | 조합 정관 (제2조·제9조·제17조) |
| 로고 | 기존 `jinjucoop.kr` 사이트 원본 PNG |
| 사진 | 조합 제공 (2026-08) |

## 색

로고 퍼즐 4색을 원본 PNG에서 추출해 그대로 쓴다.

| 이름 | 값 | 쓰임 |
|---|---|---|
| red | `#E83028` | 금산점, 강조 |
| orange | `#F0A800` | 초전점, 히어로 강조 |
| green | `#A8B048` | 생산자 |
| teal | `#00A8A8` | 진양호점 |

버튼·링크처럼 흰 글씨가 올라가는 자리는 어두운 변형(`--teal-deep` 등)을 쓴다. 원색 위 흰 글씨는 WCAG 대비가 안 나온다.

## 확인된 품질 기준

- WCAG AA 대비 통과 (본문 13.9:1, 보조 6.9:1, 최소 4.9:1)
- 가로 스크롤 없음 (1440 / 375)
- 이미지 전부 WebP + `width`/`height` 지정 (CLS 방지), 첫 화면 외 `loading="lazy"`
- `word-break:keep-all` — 한국어 어절 단위 줄바꿈
- `prefers-reduced-motion` 반영

## 아직 채우지 못한 것

- 매장별 영업시간·직통 전화 (조합 확인 필요)
- 초전점·진양호점 외관 사진 (현재 카드 이미지가 매장과 정확히 대응하지 않음)
- 공동구매 앱(`jinju-garden-client.vercel.app`) 연결 여부
